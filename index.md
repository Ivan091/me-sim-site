# me-sim

me-sim and me-studio are the creator's own desktop tools. me-sim renders code-driven 2D physics simulations,
such as bouncing balls, breaking bricks and light beams, into short vertical videos. me-studio publishes those
videos to the creator's own YouTube, Instagram and TikTok accounts and reads back how they performed.

Both tools run only on the creator's own computer. There is no server, no shared account, no analytics and no
sharing of data with third parties.

The videos are published as YouTube Shorts, for example [this one](https://www.youtube.com/shorts/12KFbzqrpN0).

The tool uses YouTube API Services. See the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the
[Google Privacy Policy](https://policies.google.com/privacy).
