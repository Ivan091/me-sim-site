# me-sim

me-sim is a desktop command-line tool that renders code-driven 2D physics simulations, such as bouncing balls,
breaking bricks and light beams, into short vertical videos and posts them to the social media accounts of the
creator who runs it. It runs on the creator's own computer. There is no server and no shared account.

The videos are published as YouTube Shorts, for example [this one](https://www.youtube.com/shorts/12KFbzqrpN0).
